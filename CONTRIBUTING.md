# Contributing to Céline

Issues and pull requests are welcome. We will do our best to take them into account to make Céline better.

## Before you open a PR

Build and run the tests. Both are in the [README](README.md).

The suite is fast and covers the engine, the schematic model and the editor. A
change that breaks it will not be merged.

## Licensing

Céline is licensed under the [GNU AGPL v3](COPYING). Contributions are accepted
under the same licence — by opening a pull request you agree your work is
licensed that way. There is no CLA.

If you add a third-party dependency, it must be compatible with the AGPL, and it
needs an entry in [`LICENSE`](LICENSE) and its verbatim licence in
[`THIRD-PARTY-NOTICES`](THIRD-PARTY-NOTICES).
